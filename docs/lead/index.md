# Lead Management Module - Backend

## Overview
The Lead Management module is responsible for capturing, tracking, and converting potential customers. It provides a robust set of features to handle the lifecycle of a lead from initial contact to closure.

## Core Features
- **Lead Capture & Storage**: Store essential details such as customer name, mobile, and product interest.
- **Assignment System**: Assign leads to specific employees or teams.
- **Activity Tracking**: Log all interactions, status changes, and remarks against a lead.
- **Follow-ups**: Schedule and track follow-up tasks.
- **Roles & Permissions**: Access control based on user roles (ADMIN, EMPLOYEE).
- **Real-time Updates**: Socket events for instant notifications upon assignments and updates.
